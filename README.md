## 🔭 What I do

I'm an AI/ML Engineer at **WISERLI**, working on computer vision pipelines from model training through to edge deployment.

- ⚡ Ported a Mask2Former segmentation pipeline to **TensorRT/FP16 on NVIDIA Jetson Orin NX**, taking it from 1-2 FPS to 5-10 FPS (up to **10x**)
- 🚁 Built drone-based vision systems with **ByteTrack + ReID + BEV projection**, sustaining **25-30 FPS** real-time analytics
- 🎯 Doubled detection/segmentation throughput (**2x**) with YOLO, SAM and RF-DETR via batching and preprocessing optimization
- 🔋 Built a multi-modal battery attribute recognition pipeline (Mask2Former + PaddleOCR + OpenCV) at **95% accuracy** on brand and color
- 🧠 Scaled LLM-based analysis workflows to **500,000+ data points**
- 🏥 Shipped 3+ production AI pipelines (healthcare and surveillance) behind **FastAPI**
